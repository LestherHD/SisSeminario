# Referencias de crecimiento OMS

Estas tablas LMS se copiaron de los repositorios oficiales de la Organización Mundial de la Salud:

- `WorldHealthOrganization/anthro`: estándares OMS 2006 para menores de 5 años.
- `WorldHealthOrganization/anthroplus`: referencia OMS 2007 para edades de 5 a 19 años.

Archivos utilizados:

- Peso para la edad.
- Longitud/talla para la edad.
- IMC para la edad.

El backend las carga localmente para calcular puntajes Z y percentiles sin depender de una conexión externa durante el uso del SCCVI.
